## 📌 Overview

This project is a hands-on Security Operations Center (SOC) laboratory built with Wazuh.

The objective is to simulate a real-world security monitoring environment where security events generated by Linux endpoints are collected, analyzed, correlated, and investigated through a SIEM platform.

The laboratory focuses on:

- Security event monitoring
- Log collection and analysis
- Threat detection
- File Integrity Monitoring (FIM)
- Vulnerability detection
- User and privilege monitoring
- Suspicious activity detection
- Alert investigation
- MITRE ATT&CK mapping
- Basic incident response

The project was built in a controlled laboratory environment for educational and cybersecurity training purposes.

The laboratory runs locally with Kali Linux hosting the Wazuh infrastructure and Ubuntu acting as a monitored security endpoint.

# 🧩 MITRE ATT&CK Mapping

Detected activities will be mapped to relevant MITRE ATT&CK techniques where applicable.

- Credential Access
- Persistence
- Privilege Escalation
- Defense Evasion
- Discovery
- Initial Access

The objective is to understand how individual security events relate to broader adversary behavior.

# 📚 Key Learnings

This project helped me understand how a SOC environment operates in practice.

I learned how security events generated by multiple endpoints can be collected by a SIEM, analyzed using detection rules, transformed into security alerts, and investigated by a security analyst.

I also learned that security monitoring is not limited to detecting an alert. An analyst must understand the context of the event, determine its severity, investigate its origin, assess its potential impact, and recommend an appropriate response.

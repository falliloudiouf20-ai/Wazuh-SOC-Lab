# 📊 Security Findings Report

## Project Overview

This report summarizes the security findings identified during the **Wazuh SOC Lab**. The objective of the laboratory was not to compromise a production environment, but to validate the ability of the Wazuh SIEM platform to detect, correlate, and investigate common security events occurring on a Linux endpoint.

Throughout the project, several attack scenarios were simulated and successfully detected by Wazuh. Each scenario generated alerts that were analyzed and mapped to the MITRE ATT&CK framework, reproducing the workflow of a Security Operations Center (SOC).

# Recommendations

The following security improvements are recommended for a production environment:

## Authentication

- Enforce strong password policies.
- Enable Multi-Factor Authentication (MFA).
- Disable password-based SSH authentication where possible.
- Restrict SSH access to trusted networks.

---

## Privileged Access

- Apply the Principle of Least Privilege.
- Audit `sudo` group membership regularly.
- Monitor privileged command execution continuously.
- Remove inactive administrator accounts.

---

## File Integrity

- Monitor critical system and application directories.
- Enable real-time File Integrity Monitoring.
- Review checksum alerts promptly.
- Maintain secure backups of critical files.

---

## Security Monitoring

- Continuously monitor endpoint activity.
- Correlate authentication and privilege escalation events.
- Regularly review SIEM alerts.
- Integrate Wazuh alerts into an incident response process.
